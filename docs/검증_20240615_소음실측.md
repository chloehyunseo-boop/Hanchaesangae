# 공단 소음 실측 자료 요약 — 2024-06-15 (하린 라인, 2026-11-27)

공단이 하린 문의에 회신으로 준 측정 원자료(10EaZy 측정기 출력 PDF)의 **요약값**이에요. 원본은 공단 제공 자료라 공개 저장소에 올리지 않아요(`data/private/`, .gitignore). 판정(통과/실패)은 하지 않아요(CLAUDE.md 8번).

## 자료
- 일시: 2024-06-15(토) 18:01~19:00, 1분 간격 60개
- 위치: 만남의광장 인근 편익동(할리스커피점 옥상) — 공단 11/26 답변의 측정 위치
- 값: 1분 Leq(dB(A)·dB(C)), 측정기가 계산한 5분 이동 Leq
- 그날 공연: 88잔디마당 '톤앤뮤직 페스티벌 2024', KSPO DOME 'AKMU 10th ANNIVERSARY CONCERT [10VE]' (공단 회신 기준, 측정 대상은 톤앤뮤직으로 보임)

## 여기서 쓸 수 있는 것
1. **5분 평균(공단 기준)과 1시간 평균(우리 엔진)의 차이**: 이 1시간에서는 5분 최댓값이 1시간 평균보다 **2.8 dB** 높았어요(측정기 표 값 61.0을 쓰면 4.2 dB). 공단 기준과 엔진 지표가 다르다는 미해결 차이를 보여 주는 실제 사례예요. 공연·시간대마다 달라서 일반화하지 않아요.
2. **기준 상한과 실제**: 이날 1시간 평균 56.8 dB(A)은 공단 기준 65 dB(A)보다 약 8 dB 낮았어요. 야외 음원 세기(엔진 입력 135)는 "편익동에서 65 dB가 나오는 공연" 상한 시나리오예요.
3. **저음이 많음**: C특성이 A특성보다 8~16 dB 높아요. 엔진의 '7개 대역 균등 분배' 가정보다 실제 공연 소리에 저음이 많다는 근거(엔진 한계로 기록).
4. **배경 소음이 큼**: L90 53.8 dB(A)으로 1시간 평균과 3 dB 차이. 실측값 중 상당 부분이 공연 소리가 아닐 수 있어요.

## 엔진 결과와 비교 (2026-11-29, 친구 라인)
그날 ASOS 서울(108) 실제 기상(`validation/asos_seoul_20240615.csv`, data.kma.go.kr 공개 조회로 직접 받음)으로 88잔디마당→편익동 소음을 계산해봤어요(`validation/case_20240615_demo.mjs`, 결과 `validation/case_20240615_demo_result.txt`).

| 항목 | 값 |
| --- | --- |
| 18시 엔진 계산(편익동, CONCAWE) | **65.8 dB(A)** |
| 18:01~19:00 공단 실측(1시간 LAeq) | 56.8 dB(A) |
| 차이 | 엔진이 약 **9dB 더 높음** |

- 그날 실제 바람(270°, 3.6m/s, 안정도 D)은 무대→편익동 방위각(125°)과 정확히 같은 방향은 아니었는데도(엔진이 풍향 부채꼴 ±22.5° 안에서 가장 큰 값을 골랐는데도) 실측보다 9dB 높게 나왔어요.
- 음원 세기(135dB)는 "편익동 쪽으로 정확히 부는 순풍·3m/s·중립 대기"라는 **최악 조건에서 딱 65dB가 나오게 역산한 값**(decisions.md 2026-11-26)이라, 실제보다 높게 잡힐 걸 어느 정도 예상은 했지만, 그 최악 조건이 아닌 실제 바람에서도 이 정도 차이가 난다는 건 그 역산값(또는 CONCAWE 최악 가정 자체)이 실제 전파보다 꽤 보수적(더 크게)이라는 뜻으로 읽을 수 있어요.
- 한계: 공연이 '톤앤뮤직 페스티벌'인지 확실치 않고(위 "자료" 참고), 공연 시작·종료 시각도 측정기록으로 역추정한 가정이라, 이 9dB 차이를 엔진의 정확한 오차로 못 박을 수는 없어요. 통과/실패는 정하지 않고 그대로 기록만 해요(CLAUDE.md §8).
