# 배출가스 엔진 현실화 변경안 (검토용)

2026-11-21 · 하린 라인 · **검토 2회 후 적용함(11/21 오후).** 동결은 DOME 높이·폭으로 건물 후류 적용 조건을 확인한 뒤 해요.

**검토 반영 요약 (적용본 기준, 아래 본문보다 우선)**
- 시나리오 이름: 기본추정 / 기존입력가정 / 연기상승제외 / 전량NO2 ('현실'·'최악' 안 씀)
- 건물 옆 발전차(기본값): 연기 상승 제외, 배기구 높이 3m는 유지. 개방된 곳이라고 명시한 발전차만 Briggs 상승 적용(하린 결정 B)
- ARM2: 수음점별로 발전차 NOx를 먼저 더한 뒤 적용. 전량NO2 민감도로 비교
- 부하율 0.43: 'EPA 모델 기본값, 실측 아님'으로 표기
- 결과 해석: '그 시간 기상이 유지된다는 가정의 1시간 평균 추정 농도'
- 배출계수: 600hp 초과(500kW=670hp)는 AP-42 3.4절 14.6 g/kWh(등급 B). 3.3절(600hp 이하)은 쓰지 않음. 3.4절이 고정식 엔진 자료라는 점은 한계
- 남은 일: DOME 높이·폭 확보 → ISC3 후류 적용 조건 확인, 최신 AERMOD 지침의 ARM2 식과 대조

## 1. 무엇이 문제였나

### 1-1. 증상

민감도 분석(`validation/plume_sensitivity.mjs`) 결과, 지금 기본 입력으로는 바람이 약한 밤에 지도 대부분이 '강'으로 나와요.

- 기본 입력: 발전차 5대(KSPO DOME 제한 상한) · 엔진 500kW · 부하율 100% · 비제어 배출계수 · NO2/NOx 0.9 · 배출 높이 0m
- 11월 맑은 밤 풍속 2m/s(안정도 F): 풍하 300m **2.0ppm**(환경기준 0.10ppm의 20배), '강'이 **3.2km**까지 이어져요.
- 엔진을 쓰지 않고 손으로 따로 계산해도 2.01ppm이라, 계산 오류는 아니에요. 값이 큰 원인은 입력 가정이에요.

### 1-2. 현실과 안 맞는 근거

- **민원 위치:** 민원(VB0000120067·120556·130318·130509)이 나온 곳은 수영장, 테니스장, 산책로예요. 모두 발전차에서 수백 m 안이에요. 수 km 밖 주거지 매연 민원은 공개글에 없어요.
- **민원 내용:** "냄새로 산책이 답답할 정도" 수준이에요. 기준의 20배 농도와는 맞지 않아요.

### 1-3. 원인: 최악 쪽 가정이 곱해져요

| 가정 | 지금 값 | 왜 과대평가인가 |
| --- | --- | --- |
| 배출 높이·연기 상승 | 0m, 상승 없음 | 실제 배기는 약 3m 높이에서 400℃ 이상으로 나와 위로 올라가요. 가까운 거리 지면 농도를 크게 키워요 |
| 부하율 | 100% | 발전기는 평균적으로 최대 출력보다 낮게 돌아요. 100%는 근거 없는 '우리 결정'이었어요 |
| NO2/NOx | 0.9 고정 | 공식 범위(0.5~0.9)의 상한이에요. 발전차 근처처럼 NOx가 진한 곳은 실제 비율이 낮아요 |
| 배출계수 | AP-42 비제어 | 엔진 등급을 몰라서 그대로 둬요(공단 답 대기) |
| 대수 | 5대 | 현재 제한 상한. 그대로 둬요 |

## 2. 바꿀 것 (3가지)

공통 원칙: 공개 표준식과 원문에서 확인한 값만 써요. 새로 만든 계수는 없어요. 지금 값은 **'최악 시나리오'**로 남겨서 비교할 수 있게 해요.

### ② NO2/NOx 0.9 고정 → ARM2 공식

ARM2는 그 지점의 NOx 농도에 따라 NO2 비율을 계산하는 EPA 방법이에요. NOx가 진할수록(발전차 가까이) 비율이 낮아요.

```latex
y = -1.1723\times10^{-17}x^6 + 4.2795\times10^{-14}x^5 - 5.8345\times10^{-11}x^4 + 3.4555\times10^{-8}x^3 - 5.6062\times10^{-6}x^2 - 2.7383\times10^{-3}x + 1.2441
```

- x = 그 지점의 NOx 농도(µg/m³), y = NO2/NOx 비율
- 출처: EPA, *ARM2 Development and Evaluation Report* (2013.9.20.), 3.4절 p.22 — https://gaftp.epa.gov/aqmg/SCRAM/models/preferred/aermod/ARM2_Development_and_Evaluation_Report-September_20_2013.pdf
- 상·하한: **0.5~0.9** — EPA *AERMOD NO2 Changes TSD* 4.1절(지금 가정값 문서에 이미 쓰는 출처). 2013 보고서 원래 하한은 0.2였는데, 이후 TSD에서 0.5로 정했어요.

| NOx (µg/m³) | 100 이하 | 150 | 200 | 300 이상 |
| --- | --- | --- | --- | --- |
| ARM2 비율 | 0.9 | 0.80 | 0.67 | 0.5 |

**0.5 고정을 안 쓰는 이유:** 지도 '강·중' 경계 근처(NOx 100~150µg/m³)는 ARM2로도 0.8~0.9예요. 0.5 고정이면 바로 그 경계를 줄여 그리게 돼요.

적용 방식: 한 지점에 대해 발전차 여러 대의 **NOx를 먼저 더한 뒤** ARM2 비율을 곱해요. 풍향 부채꼴의 방향마다 따로 계산해요.

### ③ 배출 높이와 연기 상승 (ISC3 Briggs 식)

**출처:** EPA, ISC3 사용자 지침 2권 (HWIR99판, EPA 보관본) — https://archive.epa.gov/epawaste/hazard/web/pdf/s0528.pdf. 수식은 원문 쪽을 직접 열어 확인했어요.

| 식 | 내용 | 원문 |
| --- | --- | --- |
| 1-1 | χ = QKVD / (2π u_s σy σz) · exp(−0.5(y/σy)²), u_s = **배출 높이의 풍속** | p.1-3 |
| 1-50 | 지면 수음점(z_r=0)이면 V = 2·exp(−0.5(h_e/σz)²). 혼합고 반사항은 쓰지 않음(지금과 같음) | p.1-33 |
| 1-8 | 부력 플럭스 F_b = g·v_s·d_s²·ΔT/(4T_s) = g·V·ΔT/(π·T_s) (V = 배기량 m³/s) | p.1-8 |
| 1-12~1-15 | 불안정·중립(A~D) 최종 상승: F_b<55면 Δh = 21.425·F_b^(3/4)/u_s | p.1-9~1-10 |
| 1-17 | 안정도 변수 s = g·(∂θ/∂z)/T_a, E 0.020 K/m · F 0.035 K/m | p.1-10 |
| 1-20 | 안정(E·F) 최종 상승 Δh = 2.6·(F_b/(u_s·s))^(1/3) | p.1-11 |
| 1-22 | 최종 상승 전 거리의 점진 상승 Δh = 1.60·F_b^(1/3)·x^(2/3)/u_s (최종 상승을 넘으면 최종 상승) | p.1-12 |

지금 식은 h_e = 0일 때의 특수한 경우예요. 그래서 새 식은 지금 식에 exp(−0.5(h_e/σz)²)를 곱하고, 풍속을 배출 높이 풍속으로 바꾼 것과 같아요.

민감도 확인:
- 배기 부력을 절반으로 줄여도 '강' 끝 차이는 3~6%예요.
- 배기구 높이 3.0m → 3.8m면 '강' 끝이 0.05km 안쪽으로 줄어요.

읽는 법:
- 발전차 근처 농도는 크게 내려가요(300m: 2.0 → 0.1ppm).
- 바람이 약한 안정한 밤(E·F)에는 연기가 높이 뜬 채 멀리 가요. 그래서 '강'이 1km 안팎, '중'이 수 km까지 남아요. 이건 계산 오류가 아니라, 약풍 야간 확산에서 이 모델이 내는 결과예요.
- ②는 경계(약 0.05ppm)에서 비율이 0.9 근처라 '강' 범위는 거의 안 바뀌고, 근거리 농도만 낮춰요.

## 4. 이번에도 계산하지 않는 것 (기획서에 밝힘)

- **건물 후류(다운워시):** DOME처럼 큰 건물 옆에서는 건물이 연기를 끌어내려서 연기 상승 효과가 줄 수 있어요. 지금처럼 계산하지 않고 한계로 적어요.
- **부분 부하의 배기:** 스펙시트 값은 정격(최대 출력) 기준이에요. 부하율 43%에선 배기 온도와 배기량이 더 낮아 상승이 조금 작을 수 있어요. 부력 절반 민감도로 영향을 보여요(위 3절).
- **배출계수:** 엔진 등급(Tier)을 몰라 비제어 계수를 그대로 써요. 공단이 등급을 알려 주면 바꿔요. 민감도상 결과를 가장 크게 바꾸는 항목이에요.
- **배경 농도, 혼합고 반사, 지형, 화학 반응(ARM2 외)**은 지금과 같이 넣지 않아요.

## 5. 구현 계획

1. `engine/plume.js`
    - 발전차 입력에 선택 항목 `배기구높이_m`, `배기온도_C`, `배기량_m3_per_min`을 추가해요. 없으면 2절 기본값을 쓰고 꼬리표 `배기사양가정`을 달아요.
    - 함수 입력에 `대기온도_C`(기상청 TMP)를 추가해요.
    - 시나리오 옵션: `"현실"`(①②③, 시민·공단 화면 기본)과 `"최악"`(지금 그대로: 부하율 1.0, NO2 0.9, h_e=0, 2m 풍속)을 둬요.
    - 발전차 여러 대는 NOx를 먼저 더하고 ARM2를 적용해요. 부채꼴 방향마다 계산해요.
    - 근거리 불확실(x<100m)·약풍 미표시 규칙은 그대로예요.
2. `data/assumptions.json`, `docs/발전차_배출가스_가정값과_근거.md`에 위 값과 출처를 추가해요.
3. 테스트
    - 기존 stage1~3·Turner 테스트가 `"최악"` 시나리오로 그대로 통과해야 해요(계산 결과 같음).
    - 새 손계산: F_b, 안정·중립 최종 상승, 점진 상승, ARM2 다항식(위 표 값), h_e=0이면 기존 식과 같은지.
    - 민감도 분석을 `"현실"` 기준으로 다시 돌려요.
4. 끝나면 동결해요.

## 6. 검토 받고 싶은 질문

1. **부하율 0.43 적용 범위:** NONROAD 표의 분류명이 "Diesel Light Commercial Generator Sets"예요. 500kW급 렌탈 발전기에 써도 되는지 궁금해요. 우리 판단은 이래요. 같은 SCC(2270006005)가 마력 구간 구분 없이 디젤 발전기 세트 전체에 쓰이는 값이라, 써도 된다고 봤어요.
2. **ARM2 적용 대상:** 우리는 배경 농도 없이 발전차 기여 NOx만 넣어요. AERMOD에서도 모델 계산 NOx에 ARM2를 적용하는 것과 같은 방식이라고 이해했는데, 맞는지 확인해 주세요.
3. **ARM2 하한 0.5:** 2013 보고서는 0.2, 이후 TSD는 0.5예요. 최신 문서 기준 0.5가 맞는지 확인해 주세요.
4. **배기 기본값:** 스펙시트 중 상승이 가장 작게 나오는 값을 골랐어요. 이게 타당한지 봐 주세요.
5. **점진 상승(1-22):** 원문에 "점진 상승을 쓸 경우"라고만 돼 있어요. 우리는 근거리 과소평가를 피하려고 점진 상승을 기본으로 켰어요. 이게 타당한지 봐 주세요.
6. **건물 후류:** 계산하지 않는 한계 처리로 충분한지, 아니면 DOME 바로 옆 발전차는 '최악' 시나리오만 보여 줘야 하는지 의견을 듣고 싶어요.
