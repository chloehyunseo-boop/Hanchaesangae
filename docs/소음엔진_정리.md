# 소음 엔진 정리 (검토용)

2026-11-21 · 친구 라인(소음·지도·배포) · `engine/noise.js` + `engine/combine.js` 기준

## 1. 목표

올림픽공원에서 열리는 공연의 소음이 **몇 시에, 어디까지, 얼마나** 퍼지는지를 1시간 단위로 "강/중/약" 3단계로 예보하는 게 이 엔진의 역할이에요. 공단 민원(2024-10 소음 간섭 사건 등)과 65dB 소음 기준을 근거로, 공연 시간표·기상 예보만으로 사전에 영향 범위를 가늠해보자는 거예요.

**이 엔진이 하지 않는 것** (CLAUDE.md 4번에 이미 명시):
- 관객 함성·귀가 인파 소음, 리허설 소음
- 현장 측정·센서값 사용
- "발전차를 옮기세요" 같은 해결책 제안(예보만 함)
- 실측 정확도 증명 — 결과는 "명시된 가정 아래의 시간별 확산 경향 추정"이라고만 불러요

## 2. 서비스 내용 (이 엔진이 실제로 내놓는 것)

`engine/combine.js`의 `computeHourOutputCells()`가 한 시각·격자 전체에 대해 아래 모양(`OutputCell`)의 배열을 만들어요. 시민 화면·공단 화면 둘 다 이 배열을 레이어만 바꿔서 그려요.

```js
{
  x: 127.130516,   // 경도 (지금은 위경도, 실제 좌표계는 4절 참고)
  y: 37.514512,    // 위도
  hour: "2026-11-21T19:00:00+09:00",
  layer: "noise",
  value: 36.1,     // dB(A). 계산을 아예 못 한 칸은 null(0과 다른 의미)
  level: null,     // "강"(65↑)·"중"(55~65)·"약"(45~55)·null(기준 미만)
  flags: ["지면효과미적용"],  // 이 값에 붙는 주의사항(아래 6절)
  scenario: "ISO9613-2_상한추정_지면효과미적용",
}
```

- **시간 범위**: 로드맵상 6시간(초단기예보)+3일(단기예보), 1시간 단위
- **공간 범위**: `CALC_GRID.bounds`(공원 지점들의 바운딩박스+1km) 안의 25m 격자(지금 24,178개 점)
- **3단계 기준** (CLAUDE.md 6번): 강 65dB(A) 이상 · 중 55~65 · 약 45~55, 미만이면 레이어에 안 나타남
- **지도 표시 규칙** (`common.js`의 `mapDisplayFor()`): `value`가 null이면 빈칸, `flags`에 "근거리불확실"이 있으면 숫자·단계를 숨기고 회색 빗금만 표시

## 3. 실현 방법 (수식과 근거)

### 3-1. 전체 틀: ISO 9613-2 "상한" 시나리오

```
Lp = LW + Dc − Adiv − Aatm
```

| 항 | 의미 | 상태 | 근거 |
|---|---|---|---|
| **LW** | 음원 파워레벨(dB) | ❌ 미확정 | 로드맵 '음원 세기' 항목, 공단 답 대기 — 확정 전까지 `value: null` |
| **Dc** | 무대 지향성 보정 | ✅ 항상 0 | 프로젝트 결정(`docs/올팍_좌표.md`): 스피커 방향 계산 안 함(안전측 — 무대 뒤·옆이 실제보다 시끄럽게 나옴) |
| **Adiv** | 거리 감쇠(구면 확산) | ✅ 구현+검증 | ISO 9613-2 공개식: `20·log10(d) + 11` |
| **Aatm** | 공기 흡수 | ✅ 구현+검증 | ISO 9613-1과 동일한 식(Bass et al. 1995, JASA 97(1), doi:10.1121/1.412989) — python-acoustics 등 공개 구현과 동일 |
| **Aground** | 지면 효과 | ⛔ 제외(11/21 결정) | ISO 9613-2 7.3절 원문이 유료라 못 구함 — "상한"이란 이름과 맞게 생략(지면 효과는 보통 소리를 깎아주는 방향이라 생략하면 더 높은/보수적인 값이 나옴) |
| **Abar** | 차폐(방음벽 등) | ⛔ 미반영 | CLAUDE.md 4번에 이미 "미반영"으로 정해둠 |

**바람 처리**: 수식을 바꾸는 "바람 보정항"이 아니라, 음원→수음점 방향이 예보 풍향 ±22.5° 부채꼴(`WIND_FAN_HALF_WIDTH_DEG`, common.js) 안에 들 때만 계산해요. 부채꼴 밖이면 `value: null`(그 음원 소리가 거기까지 안 간다고 봄).

**실내 공연장**: 실내 음량을 외벽 너머 파워레벨로 바꾸는 식(CLAUDE.md 6번에 이미 정해둔 공식)을 그대로 써요.

```
LW = Lp,실내 − R + 10·log10(S) − 6
```

R(외벽 투과손실)·S(외벽 면적)도 아직 가정값 단계예요(`data/assumptions.json`의 `소음_가정값.외벽_차음량` — 공동주택 일반 기준을 임시로 씀, 공연장 전용 수치 아님, 확인 필요 표시됨).

### 3-1-1. 음원 세기(LW)는 어떻게 정하나 (11/21 추가)

실제 공연이 몇 dB로 진행될지는 저희가 예측할 방법이 없어요(음악 장르·엔지니어 설정을 알 수 없음). 그래서 "예측"이 아니라 **"공단이 알려줄 기준(예: 특정 지점 65dB)을 역산해서 기본값으로 쓰고, 필요하면 조정"**하는 방식으로 정했어요.

```js
// 측정 지점에서 목표 dB가 정확히 나오는 LW를 역산 (Lp=LW+Dc-Adiv-Aatm의 역함수)
export function lwFromTargetDb({ sourceLat, sourceLon, measureLat, measureLon, targetDb, freqHz = 1000, tempC, rhPercent }) {
  const distanceM = haversineDistanceM(sourceLat, sourceLon, measureLat, measureLon);
  const adiv = calcAdiv(distanceM);
  const aatm = calcAatm(distanceM, freqHz, tempC, rhPercent);
  return { lwDb: targetDb - stageDirectivityDb() + adiv + aatm, distanceM, adiv, aatm };
}

// 공단 화면에서 조정할 때 쓰는 preset (±3dB, 로드맵 가정값)
export const VOLUME_PRESETS = { 조용한: -3, 기본: 0, 큰공연: 3 };
export function applyVolumePreset(baseLwDb, preset = "기본") { return baseLwDb + VOLUME_PRESETS[preset]; }
```

⚠️ 이건 "오늘 공연이 실제로 몇 dB였다"가 아니라 **"공연이 공단 기준치로 운영된다고 가정"**하는 거예요. 측정 지점 좌표·목표 dB·역산용 기준 날씨는 아직 공단 답 대기 중이라 진짜 숫자는 안 들어가 있어요(역산→재계산 왕복 테스트로 수식 자체는 정확함을 확인함 — 65dB 입력 → 65.0000dB로 정확히 복원).

⚠️ **11/24 수정**: 위 `lwFromTargetDb()`는 **ISO9613(①, 공단 비교용)** 전용이에요 — 1kHz 단일주파수, A가중·지면효과 없이 역산해요. 이 결과로 나온 LW를 **CONCAWE(②, 시민·공단 메인 지도)**에 넣으면 7밴드·A가중·지면효과(K3)가 추가로 깎여서 목표보다 낮게 나와요(외부 검토 실측: 65 목표 → CONCAWE 58.0dB(A), `docs/외부검토_1122_최종_분류.md`). 메인 지도용 LW는 반드시 아래 `lwFromTargetDbConcawe()`로 역산해야 해요 — "정방향과 같은 모델로 역산"이라 왕복이 정확히 맞아요(`validation/concawe_validation.mjs`에 재현·고침 테스트 둘 다 있음).

```js
// CONCAWE 쪽 역산 — calcNoiseConcaweHourly와 같은 입력(lwDb 대신 targetDb)
export function lwFromTargetDbConcawe({ targetDb, ...rest }) {
  const probe = calcNoiseConcaweHourly({ ...rest, lwDb: 0 }); // Lp는 lwDb에 선형(기울기 1)이라 한 번만 계산하면 됨
  if (probe.value === null) return { lwDb: null, flags: probe.flags, reason: probe.reason ?? "계산 불가" };
  return { lwDb: targetDb - probe.value, flags: probe.flags, category: probe.category };
}
```

### 3-2. 아직 안 된 것: CONCAWE 전체(K1~K7) 시나리오

로드맵은 ①ISO9613-2 상한과 ②CONCAWE 전체(시간별 추정) 두 시나리오를 섞지 않고 각각 쓰기로 했어요. ②는 원문(CONCAWE Report 4/81)이 스캔본이라 텍스트 추출이 안 돼서, K1~K7 항의 **이름**(기하학적 발산·대기 흡음·지면 효과·기상 보정·높이·차폐물·설비 내부 차폐)만 2차 자료로 교차 확인했고, 실제 수식은 아직 못 구했어요. `calcNoiseConcaweHourly()`는 지금 호출하면 에러를 던지는 상태예요.

### `engine/noise.js` (소음 계산 전체)

```js
// 거리 감쇠
export function calcAdiv(distanceM) {
  return 20 * Math.log10(distanceM / 1) + 11;
}

// 공기 흡수 계수(dB/m) — Bass et al. 1995 공개식
export function atmosphericAbsorptionDbPerM(freqHz, tempC, rhPercent, pressureKPa = 101.325) {
  const T = tempC + 273.15, T0 = 293.15, T01 = 273.16, pr = pressureKPa / 101.325;
  const psatOverPref = 10.0 ** (-6.8346 * (T01 / T) ** 1.261 + 4.6151);
  const h = (rhPercent * psatOverPref) / pr;
  const frO = pr * (24.0 + (4.04e4 * h * (0.02 + h)) / (0.391 + h));
  const frN = pr * (T / T0) ** -0.5 * (9.0 + 280.0 * h * Math.exp(-4.17 * ((T / T0) ** (-1 / 3) - 1.0)));
  const classical = 1.84e-11 * (1 / pr) * Math.sqrt(T / T0);
  const aO = 0.01275 * Math.exp(-2239.1 / T) * (frO / (frO ** 2 + freqHz ** 2));
  const aN = 0.1068 * Math.exp(-3352.0 / T) * (frN / (frN ** 2 + freqHz ** 2));
  return 8.686 * freqHz ** 2 * (classical + (T / T0) ** -2.5 * (aO + aN));
}
export function calcAatm(distanceM, freqHz, tempC, rhPercent, pressureKPa = 101.325) {
  return atmosphericAbsorptionDbPerM(freqHz, tempC, rhPercent, pressureKPa) * distanceM;
}

// 무대 지향성(항상 0) / 바람 게이트 / 실내 외벽 환산
export function stageDirectivityDb() { return 0; }
export function windGateFor(geometry) {
  return geometry.withinFan ? { include: true, flags: [] } : { include: false, flags: ["풍향부채꼴밖"] };
}
export function indoorFacadeSourcePowerLevel(lpIndoorDb, transmissionLossDb, wallAreaM2) {
  return lpIndoorDb - transmissionLossDb + 10 * Math.log10(wallAreaM2) - 6;
}

// 최종 조립: Lp = LW + Dc - Adiv - Aatm
export function calcNoiseIso9613Upper({ sourceLat, sourceLon, receiverLat, receiverLon, windVecFromDeg, lwDb, freqHz = 1000, tempC, rhPercent }) {
  const scenario = "ISO9613-2_상한추정_지면효과미적용";
  const geometry = sourceReceiverGeometry({ sourceLat, sourceLon, receiverLat, receiverLon, windVecFromDeg });
  const gate = windGateFor(geometry);
  const flags = [...gate.flags, "지면효과미적용"];
  if (!gate.include) return { value: null, flags, scenario };
  if (typeof lwDb !== "number" || !Number.isFinite(lwDb)) return { value: null, flags: [...flags, "음원세기미확인"], scenario };
  const adiv = calcAdiv(geometry.distanceM);
  const aatm = calcAatm(geometry.distanceM, freqHz, tempC, rhPercent);
  return { value: lwDb + stageDirectivityDb() - adiv - aatm, flags, scenario };
}
```

### `engine/combine.js` (소음 쪽, 지도용 OutputCell로 변환)

```js
export function computeNoiseCell({ source, receiver, weather, hour, freqHz = 1000 }) {
  const lwDb = source.indoor
    ? indoorFacadeSourcePowerLevel(source.indoor.lpIndoorDb, source.indoor.R, source.indoor.S)
    : source.lwDb;
  const result = calcNoiseIso9613Upper({
    sourceLat: source.lat, sourceLon: source.lon,
    receiverLat: receiver.lat, receiverLon: receiver.lon,
    windVecFromDeg: weather.windVecFromDeg, lwDb, freqHz,
    tempC: weather.tempC, rhPercent: weather.rhPercent,
  });
  return {
    x: receiver.lon, y: receiver.lat, hour, layer: "noise",
    value: result.value, level: classifyNoiseLevel(result.value),
    flags: result.flags, scenario: result.scenario,
  };
}
```

## 7. 한계와 남은 일

1. **지면 효과(Aground) 수식 미확보** — ISO 9613-2 7.3절 원문이 유료. 구하면 `calcNoiseIso9613Upper()`에 항 하나만 추가하면 돼요(구조는 안 바뀜).
2. **음원 세기(LW) 미확정** — 로드맵 '음원 세기' 항목이 아직 공단 답 대기라, 지금은 구조만 완성된 상태고 실제 공연의 dB 숫자는 안 나와요.
3. **CONCAWE 전체(K1~K7) 시나리오 미구현** — 원문 스캔본, 사용자가 PDF 직접 확인 필요.
4. **좌표계** — 아직 EPSG:5186(미터) 투영이 아니라 위경도를 그대로 써요(공원처럼 좁은 범위라 오차 1% 미만인 하버사인 공식으로 대체). 실제 5186 변환은 M3 지도 연결 때.
5. **외벽 차음량(R)·외벽 면적(S)** — 공동주택 일반 기준을 임시 가정값으로 씀, 공연장 전용 수치·3D 파일 확인 필요.
