## 읽는 법

- 노컷뉴스: 관객들은 "2막 중반부터" 외부 댄스음악이 들렸다고 함. 17:00 시작 기준이면 대략 18시 무렵부터예요(막 시작 시각은 미확인 — 추정).
- 같은 시간대에 88잔디마당 18:00 Lucky Daye, 핸드볼경기장 18:00 BoA가 시작해요. 재현 시간대는 **17:00~20:00**로 잡아요.
- 주의: setlist.fm 타임테이블은 공식 공지가 아니라 사용자 등록 자료예요. 기획서에는 '참고 자료'로 표시해요. 공식 타임테이블(주최 privatecurve 공지)을 찾으면 교체해요.
- 종료 시각은 셋 다 공식 자료에 없어요. 엔진 규칙대로 런타임 추정(투란도트 120분)으로 넣어요.
- BoA 러닝타임: 하린 기억으로 약 2시간 20분. 공개 근거를 못 찾았어요. 공단 공연정보 API(`KSCperf`)의 `extent`(소요시간) 필드로 확인하고, 없으면 '가정(근거 없음)'으로 표시해요.
