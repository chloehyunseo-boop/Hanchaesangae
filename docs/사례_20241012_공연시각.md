## 읽는 법

- 노컷뉴스: 관객들은 "2막 중반부터" 외부 댄스음악이 들렸다고 함. 17:00 시작 기준이면 대략 18시 무렵부터예요(막 시작 시각은 미확인 — 추정).
- 같은 시간대에 88잔디마당 18:00 Lucky Daye(~19:20), 핸드볼경기장 18:00 BoA가 시작해요. 재현 시간대는 **17:00~20:00**로 잡아요.
- 88잔디마당 시각은 주최 공식 타임테이블(계획표)이에요. 실제 진행은 달랐을 수 있어요(포스터에 변동 가능 표기). setlist.fm 시작 시각과도 일치해요.
- 종료 시각: 88잔디마당은 공식 타임테이블 21:20. 투란도트는 런타임 120분으로 추정, BoA는 미확인.
- BoA 러닝타임: 하린 기억으로 약 2시간 20분. 공개 근거를 못 찾았어요. 공단 공연정보 API(`KSCperf`)의 `extent`(소요시간) 필드로 확인하고, 없으면 '가정(근거 없음)'으로 표시해요.
