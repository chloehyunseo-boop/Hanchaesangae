## 쓰지 말 것
- 해외 배터리 사례(매시브 어택 등)를 "해결책"처럼 쓰지 않기(CLAUDE.md 3-4, 해결책 추천 금지). 배경("대체가 아직 어렵다")으로만.
- 2017 칼럼의 "경유 버스 몇 대 공회전 수준"은 근거 없는 추정이라 인용하지 않기.
