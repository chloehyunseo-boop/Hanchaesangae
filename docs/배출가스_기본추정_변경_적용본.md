## 1. 무엇이 문제였나

- **증상:** 기존 입력에서 11월 맑은 밤 2m/s(F)면 발전차 5대 기준 풍하 300m가 **2.03ppm**이에요. 환경기준 0.10ppm의 20배이고, '강'이 **3.2km**까지 이어져요. 엔진을 쓰지 않은 손계산으로도 같은 값이라, 계산 오류가 아니라 입력 가정 문제였어요.
- **현실과 안 맞는 근거:** 민원(VB0000120067·120556·130318·130509) 장소는 발전차에서 수백 m 안인 수영장·테니스장·산책로예요. 내용도 "냄새로 산책이 답답할 정도" 수준이에요.
- **원인:** 부하율 100%, NO2/NOx 0.9, 배출 높이 0m가 한꺼번에 곱해졌어요.

## 2. 적용한 변경과 출처

### ① 부하율 0.43

- **출처:** EPA420-P-04-005 (NR-005c, 2004.4.) 부록 표 "Load Factor and Activity Estimates in Draft NONROAD2004". 원문 행은 `2270006005  Diesel Light Commercial Generator Sets  0.43  338`이에요(PDF 27쪽, 인쇄 25쪽). [원문](https://usace.contentdm.oclc.org/digital/collection/p16021coll7/id/558)
- **성격:** EPA 모델 기본값이에요. 해당 발전차의 실측 부하율이 아니에요.
- **중복 적용 아님:** AP-42 계수는 출력 기준(g/hp-hr)이라, 출력 × 부하율 × 계수로 계산해요. 같은 문서 1쪽 식(Power × LF × EF)과 같은 구조예요.
- **코드:** `DEFAULT_LOAD_FACTOR_NONROAD = 0.43`. 부하율을 입력하지 않았을 때만 써요. 꼬리표는 `부하율EPA기본값`이에요.

### ② ARM2

- **식:** y = −1.1723×10⁻¹⁷x⁶ + 4.2795×10⁻¹⁴x⁵ − 5.8345×10⁻¹¹x⁴ + 3.4555×10⁻⁸x³ − 5.6062×10⁻⁶x² − 2.7383×10⁻³x + 1.2441
- **변수:** x = 1시간 NOx(µg/m³), 결과는 R = max(0.5, min(0.9, y))
- **출처:** 다항식은 [ARM2 보고서(2013.9.20.)](https://gaftp.epa.gov/aqmg/SCRAM/models/preferred/aermod/ARM2_Development_and_Evaluation_Report-September_20_2013.pdf) 3.4절 p.22, 상·하한 0.5~0.9는 AERMOD NO2 Changes TSD 4.1절이에요. 2013 보고서 원래 하한 0.2는 쓰지 않아요.
- **적용 순서:** 수음점마다, 풍향 부채꼴의 방향마다 발전차 NOx(g/m³)를 더해요 → ×10⁶ → ARM2 비율 → NO2 → ppm 순서예요. AERMOD도 수음점별로 모델 NOx를 합산한 뒤 ARM2를 적용해요.
- **코드:** `arm2Ratio()`, `calcExhaustAtReceiver` 안의 `toNo2()`
- **한계:** 배출 초기 NO2 비율이 높으면 ARM2가 과소평가할 수 있어요. 그래서 '전량NO2' 민감도로 비교해요.

### ④ 그대로 둔 것

- **배출계수:** 500kW(670hp)는 600hp를 넘어서 AP-42 **3.4절** 14.6 g/kWh(비제어, 등급 B)를 써요. 3.3절(600hp 이하, 18.8)은 이 출력에선 쓰지 않아요. 3.4절이 고정식 엔진 자료라는 점과 엔진 등급(Tier)을 모른다는 점은 한계로 적어요.
- **대수:** 5대(DOME 제한 상한), 확산계수, 안정도, 부채꼴, 약풍·근거리 규칙은 그대로예요.

## 4. 계산하지 않는 것 (기획서에 밝힘)

- **건물 후류:** ISC3 Huber-Snyder·Schulman-Scire처럼 건물 높이·폭·풍향으로 판정하고 확산계수를 바꾸는 방식은 구현하지 않았어요. 건물 옆 발전차는 상승을 빼는 보수적 선택만 했어요.
- **부분 부하 배기:** 정격 배기 값을 써요. 부하율 43%에선 실제 상승이 더 작을 수 있어요. 건물 옆은 어차피 상승을 빼서 영향이 없어요. 개방된 곳만 해당해요.
- **배기구 끝 하강:** 배출 속도를 알려면 지름이 필요해서, 지름을 입력하지 않은 발전차(기본값)에는 적용되지 않아요. 지름 0.2m 가정이면 배출 속도 46m/s라 영향이 없지만, 큰 지름(예: 0.8m)이면 바람이 셀 때 적용돼야 해요.
- **운동량 상승, 배경 농도, 혼합고 반사, 지형, ARM2 외 화학 반응**

## 5. 검토 이력

**1차 검토에서 받아들인 것**
- 부하율 표기를 "EPA 기본값, 실측 아님"으로 바꿈
- ARM2는 수음점별로 적용
- 하한 0.5 확인
- 배기구 높이는 '가정값'으로 표기
- 정격 배기 값의 한계 명시
- 시나리오 이름 변경

**1차 검토에서 반박한 것**
- **부하율 중복 적용:** 아니에요. EPA 문서 식으로 확인했어요.
- **평균 시간 불명확:** ISC3 식 1-1이 시간 농도예요.

**2차 검토에서 받아들인 것**
- 결과 해석 문구
- x_f 비교 테스트
- 상승 제외 ≠ 후류 계산
- 0.42ppm은 민감도 결과로 표기
- 전량NO2 민감도
- 4개 시나리오 이름

**2차 검토에서 바로잡은 것**
- "AP-42 3.3절은 600hp 이하라 500kW에 안 맞음"은 오해예요. 600hp를 넘으면 3.4절을 써요.

**코드 검토(새 세션, 동결 전)에서 고친 것**
- P1: 부력 상승 식을 부력 지배일 때만 쓰도록 판정 추가(위 2-③)
- P2: 안정도 계산에 위도·경도 검증 추가(NaN이 그럴듯한 안정도로 바뀌던 문제)
- 테스트 보강: 점진 상승 값 직접 대조, 두 대 계산을 엔진과 따로 독립 손계산

**코드 검토 2차(새 세션, 엔진을 직접 실행)에서 고친 것**
- P1: 부력에 의한 확산(BID, 식 1-48·1-49) 추가 — 빠져 있어서 개방된 곳 근거리(안정한 밤 100~150m)가 0에 가깝게 낮게 나왔어요. '강' 끝 거리는 거의 그대로예요
- P2: 대기온도 null도 '기온 없음'으로 받음(지도 시간대 전체가 계산불가가 되던 문제)
- P3: 점진 상승은 원문상 선택 옵션임을 표기, 배기구 끝 하강(식 1-7) 추가(지름 입력 시), JSDoc 위치 정리
- 수식·계수·단위·적용 순서·부채꼴·경계 조건은 '일치/정상' 판정. 중력가속도 9.81(원문 기호표 9.80616)은 차이 약 0.04%라 그대로 둠
