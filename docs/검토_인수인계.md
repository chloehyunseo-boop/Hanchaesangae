## 검토 계획 (2~5번, 이번 세션 할 일)

### 2. 코드 검토
- **엔진과 화면이 같은 값을 내는지:** 같은 시각을 엔진에 직접 넣은 값과 시민/공단/사례 화면 값이 일치하는지 3개 시각에서 비교.
- **표시 규칙 4가지:** 빈칸/점무늬/빗금/색. 각각 일부러 만들어 맞게 그려지는지. 특히 '모름'이 '조용함(빈칸)'으로 보이는 경우가 없는지. (`engine/common.js` mapDisplayFor, `app/contour_layer.js`)
- **시간대:** 브라우저 시간대를 독일·인도(30분 시차)로 바꿔도 시각 표시·기상값이 KST 기준인지. 참고: `hourSlotDate`는 브라우저 로컬 시각 기준 정시 절사라 30분 시차에서 어긋날 수 있음 — 중점 확인.
- **날짜 경계:** 자정 넘김, 11/30→12/1 월말, 72시간 끝 칸.
- **입력 방어(공단 화면):** 빈칸, 셋업이 공연보다 늦음, 과거 날짜, 출력 99999kW, 이모지·따옴표 공연명(innerHTML로 그리는 곳 → 화면 깨짐/스크립트 삽입 확인).
- **저장:** Safari 개인정보 보호 모드에서 localStorage가 막혀도 화면이 안 죽는지.
- **금지 문구:** "예보"(기상청 예보 외), 조치 권고("옮기세요" 등), ~요체를 세 화면 전체에서 검색.
- **독립 검토:** 이 코드를 만든 적 없는 별도 검토자(서브에이전트)에게 처음부터 보게 하기 — 사용자에게 먼저 물어보기.

### 3. 화면 테스트 (하린 + 언니, 기기 나눠서)
기기: 맥북 Safari 전체화면 / 맥북 Chrome / 창 좁게(1280px) / 아이패드 / 아이폰 / 안드로이드(있으면)
화면마다:
1. 처음 열었을 때 3초 안에 지도, 콘솔 에러 0
2. 공연 있는 저녁(18~21시): 소음·배출가스가 뜨고 문장 예측이 지도와 맞는지
3. 회색 구간(약풍) 시각: 점무늬/"계산 불가" 문구
4. 72시간 끝까지 막대 빠르게 끌기·연타: 멈춤이나 엉뚱한 결과 없음
5. 레이어 둘 다 끄기/하나만
6. 새로고침, 뒤로가기, 다른 기기에서 열기
공단 화면 추가: 공연 추가(셋업 포함)→저장→수정→삭제, 발전차(공연 고르기)·'사용 안 함', 새로고침 후 유지, 기록 CSV를 **엑셀로 열 때 한글 깨짐**, 날짜 눌러 이동.
사례 화면: 2024-10-12 재현이 `docs/사례_20241012_공연시각.md`와 같은지.
나쁜 환경: 느린 인터넷·오프라인·데이터 파일 못 받을 때 오류 안내.
역할: 하린 = 배출가스·문장 예측·사례 / 언니 = 소음·지도·배포. 문제는 스크린샷+시각+기기로 받기.
Claude는 Playwright(Chromium)로 데스크톱·모바일 크기 스크린샷을 직접 찍어 1차 확인 가능.

### 4. 숫자·사실 대조 (기획서와 같이)
화면과 기획서의 숫자·사실(65dB, KSPO DOME 5대, 2.8 dB, 0.10 ppm, 대관가동률 88.271%, 민원 번호 등) 전부를 표 하나로 출처와 대조. 출처 못 찾으면 뺌. 근거 모음: CLAUDE.md 9번, `docs/근거_매연_외부자료.md`, `docs/민원_정리.md`, `docs/강중약_의미.md`, `docs/발전차_배출가스_가정값과_근거.md`(⚠️ 11/22 배출가스 기획서 문구는 옛 버전 — 지금 엔진은 v2: 인증 Tier 4 Final 0.40 g/kWh 기본).
