같은 엔진 코드(`engine/`)를 Node로 돌려 손계산·문헌값과 비교해요.
로드맵 7번 "검증 계획" 참고. 11/20(M2)에 실제 스크립트를 넣어요.

## Turner 워크북 예제 비교 (2026-11-20) — `plume_turner_test.mjs`

출처: D. Bruce Turner, *Workbook of Atmospheric Dispersion Estimates*, EPA AP-26 (1970), [EPA NEPIS 원문](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=9100JEIO.txt)

| 항목 | 결과 |
| --- | --- |
| 농도 식 (문제 26, 지면 배출·지면 수용점, 7개 거리) | 7개 모두 교재가 적은 마지막 자릿수 ±1 이내 (최대 차이 3.2%, 10 km — 1.354×10⁻²를 두 자리로 쓰면 1.4×10⁻²) |
| 문제 26의 10 km 줄 | NEPIS 텍스트엔 "1.4 x 10-3"이지만 원문 쪽 이미지는 1.4 x 10⁻² (OCR 오류, 11/20 이미지로 확인) → 판정에 포함 |
| 안정도 (문제 1·5·20·21·26, 가을 오후 문제) | 6개 모두 교재와 같음 (대표 시각은 우리가 고름) |
| 맑은 여름 오후 6 m/s | 13~14시 C(교재와 같음), 15~16시 D — 교재가 시각을 안 줌 |
| 흐린 여름 낮 4 m/s | 기본 시나리오 C, 비교 시나리오 D(교재 D) — 알려진 근사 차이 |
| 확산폭 σ (참고) | 엔진(도시형)이 교재(시골형)보다 2~4배 넓음 → 같은 조건이면 엔진 농도가 더 낮음 |

## 배출가스 민감도 분석 (2026-11-21) — `plume_sensitivity.mjs`

전체 표: `plume_sensitivity_result_25m.md` (격자 25m, 6,000여 칸 × 기상 3가지 × 바꾼 값 15가지). 통과/실패 없이 기록만 해요.

기준(시연용): 발전차 4대(KSPO DOME 제한 4~5대의 아래값, VB0000130509)·500kW·부하율 100%·DOME 중심, 서풍.

| 바꾼 값 | 단계가 바뀐 칸 비율 (맑은 밤 F / 흐린 밤 D / 여름 밤 F) | 읽는 법 |
| --- | --- | --- |
| 풍속 −1m/s (흐린 밤 4→3m/s) | — / **63%** / — | 안정도가 D→E로 한 단계 바뀌면 결과가 크게 뒤집혀요. 가장 민감한 지점 |
| 부하율 50% | 16% / **40%** / 25% | 부하율은 근거 없는 '우리 결정'이라 실제 값이 중요해요 |
| 대수 8대 (2월 이전 상한) | 15% / **39%** / 16% | 공단의 대수 제한 효과가 지도에 보여요 |
| 위치 남·북 50m | 23% / 20% / 24% | 발전차 위치 확인이 필요해요 |
| 엔진 출력 800kW / 300kW | 9% / 25% / 10% · 5% / 12% / 7% | |
| 이류 풍속 10m 그대로 | 11% / 19% / 13% | 2m 보정 가정의 영향 |
| 풍속 +1m/s, 대수 5대, 부하율 75% | 4~13% | 작은 변화 |
| 하늘상태 한 단계, 비교 시나리오 | 0% | ISC3 도시형은 E·F 확산계수가 같아서, 이 조건에선 E↔F가 바뀌어도 결과가 같아요 |
| 참고: Tier 4 인증 배출계수 | 98% / 100% / 99% | 배출계수 선택이 다른 모든 항목보다 압도적으로 커요 |

주의: 맑은 밤(F)에는 기준 입력에서 '강'이 풍하 2km 넘게 이어져 계산 영역(동쪽 끝 약 1.3km) 밖까지 가요. 그래서 F 조건의 변화율이 작게 나온 건 결과가 튼튼해서가 아니라 지도가 이미 '강'으로 꽉 차서예요(풍하 300m 1.6ppm, 1km 0.21ppm — 기준 0.10ppm 대비).
