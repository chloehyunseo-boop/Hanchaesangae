출처: D. Bruce Turner, *Workbook of Atmospheric Dispersion Estimates*, EPA AP-26 (1970), [EPA NEPIS 원문](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=9100JEIO.txt)

| 농도 식 (문제 26, 지면 배출·지면 수용점, 7개 거리) | 7개 모두 교재가 적은 마지막 자릿수 ±1 이내 (최대 차이 3.2%, 10 km — 1.354×10⁻²를 두 자리로 쓰면 1.4×10⁻²) |
| 문제 26의 10 km 줄 | NEPIS 텍스트엔 "1.4 x 10-3"이지만 원문 쪽 이미지는 1.4 x 10⁻² (OCR 오류, 11/20 이미지로 확인) → 판정에 포함 |

## 배출가스 민감도 분석 (2026-11-21) — `plume_sensitivity.mjs`

전체 표: `plume_sensitivity_result_25m.md` (격자 25m, 24,178칸 × 기상 3가지 × 바꾼 값 15가지). 통과/실패 없이 기록만 해요.

기준(시연용): 발전차 **5대**(KSPO DOME 제한 '최대 4~5대'의 상한, VB0000130509)·500kW·부하율 100%·DOME 중심, 서풍.

| 바꾼 값 | 단계가 바뀐 칸 비율 (11월 맑은 밤 2m/s F / 11월 흐린 밤 4m/s D / 7월 맑은 밤 3m/s F) | 읽는 법 |
| --- | --- | --- |
| 참고: Tier 4 인증 배출계수 | 97% / 100% / 98% | 배출계수 선택이 다른 모든 항목보다 압도적으로 커요 |
| 풍속 −1m/s (흐린 밤 4→3m/s) | 4% / **58%** / 9% | 안정도가 D→E로 한 단계 바뀌면 결과가 크게 뒤집혀요 |
| 부하율 50% | 15% / **33%** / 17% | 부하율 100%는 근거 없는 '우리 결정'이라 실제 값이 중요해요 |
| 대수 8대 (2월 이전 상한) | 10% / 28% / 11% | 공단의 대수 제한 효과가 지도에 보여요 |
| 엔진 출력 800kW | 9% / 27% / 10% | |
| 위치 남·북 50m | 23% / 20% / 23% | 발전차 위치 확인이 필요해요 |
| 이류 풍속 10m 그대로 | 10% / 20% / 11% | 2m 보정 가정의 영향 |
| 대수 4대, 부하율 75%, 엔진 300kW, 풍속 +1m/s | 4~15% | 작은 변화 |
| 하늘상태 한 단계, 비교 시나리오 | 0% | ISC3 도시형은 E·F 확산계수가 같아서, 이 조건에선 E↔F가 바뀌어도 결과가 같아요 |

주의: 바람이 약한 밤(E·F, 대략 5m/s 이하)에는 기준 입력에서 '강'이 풍하 1.6~3.8km까지 이어져 계산 영역(동쪽 끝 약 1.3km) 밖까지 가요. 그래서 F 조건의 변화율이 작게 나온 건 결과가 튼튼해서가 아니라 지도가 이미 '강'으로 꽉 차서예요.
